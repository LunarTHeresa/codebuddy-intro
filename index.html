CodeBuddy Code是基于GLM-5.0的AI编程助手，具备以下核心能力：

📁 文件系统操作

Read/Write/Edit/MultiEdit

详细功能说明

Read工具：读取文件内容，支持行号限制

Read(file_path="/src/app.js", limit=50)

Write工具：创建新文件或覆盖现有文件

Write(file_path="/src/utils.js", content="export const sum = (a,b) => a+b")

Edit工具：精确文本替换

Edit(file_path="/src/app.js", old_string="var x=1", new_string="const x=1")

🔍 智能搜索系统

Glob/Grep高级搜索

搜索功能详解

Glob工具：按模式匹配文件

Glob(pattern="src/**/*.js")

Grep工具：正则表达式内容搜索

Grep(pattern="function\\s+\\w+", glob="src/**/*.js")

⚡ 命令执行引擎

Bash Shell集成

执行环境说明

Bash工具：安全的命令执行

Bash(command="npm install", description="安装依赖")

支持后台运行、超时控制、环境变量设置
