CodeBuddy Code 技术手册

第1章：概述

CodeBuddy Code 是基于GLM-5.0的命令行AI编程助手。

核心能力：

  • 文件操作：Read、Write、Edit
  • 搜索：Glob、Grep
  • 命令执行：Bash
  • 版本控制：Git

第2章：工具详解

Read工具

读取文件内容

Read(file_path="/src/app.js", limit=50)

Write工具

创建新文件

Write(file_path="/src/utils.js", content="export const sum=(a,b)=>a+b")

Edit工具

精确替换文本

Edit(file_path="/src/app.js", old_string="var x=1", new_string="const x=1")

Bash工具

执行Shell命令

Bash(command="npm install express", description="安装依赖")

第3章：工作流程

添加API接口：

  1. Glob("src/**/routes/*.js") 搜索路由文件
  2. Read("src/app.js") 读取主文件
  3. Write("src/controllers/user.js") 创建控制器
  4. Edit("src/routes/index.js") 添加路由
  5. Bash("curl localhost:3000/api/users") 测试

第4章：实战技巧

提高效率：

  • 创建CODEBUDDY.md定义规范
  • 复杂任务先用Plan模式制定计划
  • 重要操作前Git commit备份
