什么是 CodeBuddy Code？

CodeBuddy Code 是一款运行在命令行环境的 AI 编程助手，它不仅能理解你的自然语言指令，还能直接操作你的代码库——读取、编写、编辑文件，执行终端命令，管理 Git 工作流。

与传统 AI 编程助手不同，CodeBuddy Code 具备完整的工具链能力。当你说"帮我修复这个 bug"时，它会主动搜索相关代码、分析问题根源、修改文件并验证修复效果，全程无需你手动干预。

核心优势

  • 自主执行 — 自动完成文件读写、命令执行、Git 操作，无需手动复制粘贴
  • 上下文理解 — 自动探索代码库，理解项目结构和依赖关系
  • 任务规划 — 将复杂任务分解为可执行步骤，逐个完成并跟踪进度
  • 安全可控 — 敏感操作需要用户确认，支持权限级别配置

使用指南

从安装到精通，一步步掌握 CodeBuddy Code

01

安装与配置

CodeBuddy Code 以命令行工具形式运行。首次使用需要进行简单的配置：

安装 
# 通过 npm 安装
npm install -g @codebuddy/codebuddy-code

# 或使用 npx 直接运行
npx @codebuddy/codebuddy-code

配置文件位于 ~/.codebuddy/config.json，可以设置：

  • API Key — GLM-5.0 模型的访问密钥
  • 权限级别 — auto（自动执行）或 plan（先规划后执行）
  • 忽略文件 — 配置哪些文件不应该被访问
02

基本交互

在项目目录中启动 CodeBuddy Code，使用自然语言描述你的需求：

对话示例 
用户: 当前项目的入口文件在哪里？

CodeBuddy: 让我搜索一下...
找到入口文件：src/index.ts

用户: 帮我添加一个健康检查接口

CodeBuddy: 正在读取 src/index.ts...
正在添加 /health 端点...
已完成。新的接口返回 { status: "ok" }
提示：描述任务时越具体越好。说明文件位置、期望行为、技术栈等信息，可以帮助我更准确地完成任务。
03

读取文件
自动执行

写入/修改文件
需要确认
首次修改新文件时确认
执行命令
需要确认
根据命令风险级别
Git 推送
需要确认
影响远程仓库的操作
04

斜杠命令

进阶技巧

掌握这些技巧，让 CodeBuddy Code 发挥最大价值

🎯

提供上下文信息

在请求中包含相关背景：使用的框架、目标平台、性能要求等。例如：

❌ "写一个登录功能"
✓ "用 Next.js App Router 实现登录功能，使用 NextAuth.js，支持 GitHub OAuth"
📋

利用 CODEBUDDY.md

在项目根目录创建 CODEBUDDY.md 文件，记录项目规范、架构决策、编码风格。CodeBuddy Code 会自动读取并遵循这些约定。

# 项目规范

## 技术栈
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS

## 编码规范
- 使用函数组件和 Hooks
- 组件文件使用 PascalCase
- 工具函数放在 lib/ 目录
🔄

任务分解与规划

对于复杂任务，可以先让我制定计划，确认后再执行。这样可以避免方向偏差，也方便你审核每个步骤。

✓ "帮我重构用户模块，先列一个计划"

我会创建任务列表，你可以审核、调整顺序，然后逐一执行

🔍

善用探索模式

在不确定如何实现时，先让我探索代码库，了解现有实现。例如：

用户: 这个项目是怎么处理用户认证的？

CodeBuddy: 让我探索一下...
找到了认证相关的代码：
- src/middleware.ts - 路由保护
- src/lib/auth.ts - 认证逻辑
- src/app/api/auth/ - API 路由

使用的是 NextAuth.js，配置了...
⚙️

MCP 扩展

通过 Model Context Protocol (MCP) 扩展能力。可以连接数据库、调用外部 API、集成第三方服务。

常用 MCP 服务器：

  • filesystem — 扩展文件系统访问
  • github — GitHub API 集成
  • sqlite/postgres — 数据库操作
  • puppeteer — 浏览器自动化
👥

团队协作模式

创建多个 Agent 并行处理任务。每个 Agent 专注不同领域：前端、后端、测试等。

用户: 创建一个团队来重构这个项目

CodeBuddy: 创建团队 [refactor-team]
- architect: 分析现有架构
- frontend-dev: 重构组件
- backend-dev: 优化 API
- tester: 编写测试用例
